Seleva · App review demonstration

Version 0.9.1 (54) · Galaxy Z Flip5 · Android 16 · Recorded October 6, 2026

Seleva compares photos on the device and groups similar photos so the user can choose which to keep. This page requires no login.

User-initiated photo analysis

Select an album and date range, then tap 분석 시작 (Start analysis). The app reads the photos the user has allowed, performs local analysis, displays progress and a cancel control, and shows the completed results.

The demonstration continues through similar-photo groups, two-photo comparison, selection for cleanup, and the Android system trash confirmation. The system request is cancelled; no photo is actually moved in this recording.

Idle waiting and introductory guidance were removed in chronological order. The analysis segment is not sped up. App screens have not been synthesized. The status bar was cropped to exclude personal notifications.

Foreground service declaration

FOREGROUND_SERVICE_DATA_SYNC · Local processing: Other.

The user starts photo analysis explicitly. WorkManager runs the analysis as foreground work and the app provides progress and cancellation. Processing can take longer for a larger selection. Deferring the task delays the comparison results the user requested. If interrupted, valid analysis results are retained locally and can be reused on a retry. The app does not initiate periodic new photo scans.

Photo processing is on-device; this release contains no network permission or advertising SDK. A foreground service was observed during the recorded analysis. This recording shows the initiation, in-app progress and results; it does not show a notification-panel or background-switching demonstration.
